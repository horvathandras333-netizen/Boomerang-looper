# Workspace Rules for Boomerang Looper

## Communication Style
- **Keep responses high-level and concise**. Do not include verbose technical logs, line-by-line breakdowns, or unnecessary low-level details. Provide clean, direct summaries of actions taken and final results.

## Documentation Maintenance
- **Always update `README.md`** whenever adding new features, changing UI controls, modifying FFmpeg pipeline logic, or altering project usage instructions.
- Ensure `README.md` remains a complete and accurate reference for all features, requirements, installation, and usage steps.
